Hi, I'm Miguel.
Based in Argentina, my favorite passion is designing and building web interfaces using semantic HTML and pure CSS. I am driven by the challenge of developing smooth animations, interactive components, and responsive layouts—completely library-free—to craft stunning, high-performance user experiences.

Maquetacion77 was born from a simple yet powerful conviction: web interfaces can always be “just a bit better.” In a digital landscape where websites often look identical due to pre-packaged frameworks, I enjoy designing custom web components from scratch, always striving for striking aesthetics.
